# Bitcoin Simulation (비트코인 시뮬레이션)

비트코인 1년치 과거 데이터를 기반으로 다양한 매매 전략을 시뮬레이션하는 도구입니다.

## 기술 스택 (Tech Stack)

- **Framework**: React (Vite)
- **State Management**: **Zustand**
- **Styling**: **Tailwind CSS**
- **UI Components**: **shadcn/ui** (모든 UI 요소는 shadcn/ui를 기반으로 구현)

## 주요 기능 (Features)

- **과거 데이터 선택**: 1분부터 일주일 단위까지의 비트코인 과거 데이터 로드.
- **매매 전략 시뮬레이션**: 수량 고정 및 다양한 배율의 마틴게일 전략 적용.
- **결과 분석**: 수익률, 승률, 최대 배율, 사이클 수 등 상세 지표 제공.
- **거래 내역**: 시간별 구매/판매 상세 내역 리스트 출력.

## 상세 구현 명세 (Implementation Details)

### 1. 주요 함수 (Core Functions)

1.  **Upbit 데이터 조회 (1분봉 1년치)**
    *   한 번에 200개 캔들 조회, 총 2628회 조회.
    *   Rate Limit 준수: 1초당 10번 호출.
2.  **간격별 데이터 생성**
    *   원본 데이터(1분봉)를 기반으로 5분, 15분, 1시간, 2시간, 1일, 2일, 일주일 단위 데이터 생성.
3.  **기울기(Slope) 데이터 계산**
    *   수식: `현재 가격 - 이전 가격`.
    *   **예외 처리**: 데이터의 첫 번째 로우는 이전 가격이 없으므로 기울기를 `undefined`로 기록.
    *   모든 간격별 데이터 생성 직후 기울기 계산 프로세스 필수 실행.
4.  **매매 기록 시스템 (Trading System)**
    *   기울기가 변할 때마다 매매 진행 (매수 + 매도 = 1 사이클).
    *   **매수 (Long)**: 기울기가 음수(-)에서 양수(+)로 변할 때.
    *   **매도 (Short/Close)**: 기울기가 양수(+)에서 음수(-)로 변할 때.
    *   **예외 처리**: `undefined`에서 음수(-)로 변하거나, `undefined`에서 양수(+)로 변하는 경우는 매매를 수행하지 않고 무시함.

### 2. UI 구성 요소 및 로직

*모든 UI 컴포넌트는 **shadcn/ui**의 가이드를 따르며, 일관된 디자인 시스템을 유지한다.*

#### 간격 버튼 (Interval Buttons)
*   **상태: 회색 (데이터 없음)**
    *   클릭 시 버튼에 '로딩 중' 표시.
    *   1분 간격: Upbit API를 통해 1년치 데이터 조회 -> **기울기 계산** -> 완료 후 저장 (`hist1min`).
    *   기타 간격: 저장된 1분 데이터를 기반으로 생성 -> **기울기 계산** -> 완료 후 저장 (`hist5min`, ...).
    *   완료 시 버튼 색상을 흰색(또는 활성 상태 색상)으로 변경.
*   **상태: 흰색 (데이터 있음)**
    *   클릭 시 해당 간격에 대한 시뮬레이션 버튼들을 활성화(Disabled 해제).

#### 시뮬레이션 버튼 (Simulation Buttons)
*   **상태: 회색 (결과 없음)**
    *   클릭 시 버튼에 '로딩 중' 표시.
    *   설정된 전략(수량 고정 등)에 따라 매매 기록 생성 및 저장 (`simul1min1x`, ...).
*   **상태: 흰색 (결과 있음)**
    *   클릭 시 해당 시뮬레이션의 상세 결과 화면 표시.
