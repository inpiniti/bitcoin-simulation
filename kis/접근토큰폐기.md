# 접근토큰폐기(P) [인증-002]

## API 정보

| 항목 | 내용 |
|------|------|
| **Method** | POST |
| **URL** | /oauth2/revokeP |
| **실전 Domain** | https://openapi.koreainvestment.com:9443 |
| **모의 Domain** | https://openapivts.koreainvestment.com:29443 |
| **실전 TR ID** | - |
| **모의 TR ID** | - |
| **Format** | JSON |
| **Content-Type** | application/json; charset=UTF-8 |

## 개요

부여받은 접근토큰을 더 이상 활용하지 않을 때 사용합니다.

---

## 요청 (Request)

### Header
```
Content-Type: application/json; charset=UTF-8
```

### Body

| Element | 한글명 | Type | Required | Length | Description |
|---------|--------|------|----------|--------|-------------|
| **appkey** | 고객 앱Key | String | Y | 36 | 한국투자증권 홈페이지에서 발급받은 appkey (절대 노출되지 않도록 주의해주세요.) |
| **appsecret** | 고객 앱Secret | String | Y | 180 | 한국투자증권 홈페이지에서 발급받은 appsecret (절대 노출되지 않도록 주의해주세요.) |
| **token** | 접근토큰 | String | Y | 286 | OAuth 토큰이 필요한 API 경우 발급한 Access token<br><br>**일반고객**<br>- Access token 유효기간 1일<br>- OAuth 2.0의 Client Credentials Grant 절차를 준용<br><br>**법인**<br>- Access token 유효기간 3개월<br>- Refresh token 유효기간 1년<br>- OAuth 2.0의 Authorization Code Grant 절차를 준용 |

#### Request Body 예시
```json
{
  "appkey": "your_appkey_here",
  "appsecret": "your_appsecret_here",
  "token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9..."
}
```

## 응답 (Response)

### Header
```
Content-Type: application/json; charset=UTF-8
```

### Body

| Element | 한글명 | Type | Required | Length | Description |
|---------|--------|------|----------|--------|-------------|
| **code** | 응답코드 | String | N | 8 | HTTP 응답코드 |
| **message** | 응답메세지 | String | N | 450 | 응답메세지 |

#### Response Body 예시
```json
{
  "code": "200",
  "message": "접근토큰이 정상적으로 폐기되었습니다."
}
```

## 사용 예시

### cURL
```bash
curl -X POST "https://openapi.koreainvestment.com:9443/oauth2/revokeP" \
  -H "Content-Type: application/json" \
  -d '{
    "appkey": "your_appkey",
    "appsecret": "your_appsecret",
    "token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9..."
  }'
```

### Python
```python
import requests

url = "https://openapi.koreainvestment.com:9443/oauth2/revokeP"
headers = {
    "Content-Type": "application/json"
}
data = {
    "appkey": "your_appkey",
    "appsecret": "your_appsecret",
    "token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9..."
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result["message"])
```
