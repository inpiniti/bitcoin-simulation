# 해외주식 거래량급증 API [해외주식-039]

## 기본 정보

| 항목 | 내용 |
|------|------|
| **Method** | GET |
| **URL** | `/uapi/overseas-stock/v1/ranking/volume-surge` |
| **실전 Domain** | `https://openapi.koreainvestment.com:9443` |
| **모의 Domain** | 미지원 |
| **실전 TR ID** | HHDFS76270000 |
| **모의 TR ID** | 모의투자 미지원 |
| **Format** | JSON |
| **Content-Type** | `application/json; charset=utf-8` |

## 개요

해외주식의 거래량 급증 종목을 조회하는 API입니다.

N분 전 대비 거래량이 급증한 종목을 거래량 조건과 함께 필터링하여 조회할 수 있습니다.

## 사용 예시

### 나스닥 5분전 대비 거래량 급증 종목 (거래량 1만주 이상)

```
GET /uapi/overseas-stock/v1/ranking/volume-surge?KEYB=&AUTH=&EXCD=NAS&MIXN=3&VOL_RANG=3
```

### 뉴욕 거래소 30분전 대비 거래량 급증 종목 (거래량 100만주 이상)

```
GET /uapi/overseas-stock/v1/ranking/volume-surge?KEYB=&AUTH=&EXCD=NYS&MIXN=7&VOL_RANG=5
```

## 참고사항

- 이 API는 연속조회(tr_cont)를 지원하지 않습니다.
- `n_tvol`, `n_diff`, `n_rate` 필드를 통해 지정한 N분 전과의 거래량 비교 정보를 확인할 수 있습니다.
- 거래량 조건을 통해 일정 수준 이상의 거래량이 있는 종목만 필터링할 수 있습니다.
- 거래량 급증은 단기 변동성이나 이슈 발생을 감지하는데 유용합니다.
