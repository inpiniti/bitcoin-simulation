# 해외주식 실시간지연체결가 [실시간-007]

## API 정보

| 항목 | 내용 |
|------|------|
| **Method** | POST |
| **URL** | /tryitout/HDFSCNT0 |
| **실전 Domain** | ws://ops.koreainvestment.com:21000 |
| **모의 Domain** | 모의투자 미지원 |
| **실전 TR ID** | `HDFSCNT0` |
| **모의 TR ID** | 모의투자 미지원 |
| **Format** | JSON |
| **Content-Type** | utf-8 |

## 개요

해외주식 실시간지연체결가의 경우 기본적으로 무료시세(지연체결가)가 제공되며, 아시아 국가의 경우 유료 서비스 신청 시 API로도 유료시세(실시간체결가)를 받아보실 수 있습니다.

- **지연시간**:
    - 미국: 실시간 무료 (0분 지연)
        - 단, 장중 당일 시가는 상이할 수 있으며 익일 정정 표시됨
    - 아시아 (홍콩, 베트남, 중국, 일본): 15분 지연
        - 중국은 실시간시세 신청 시 무료 실시간 시세 제공

해당 API로 **미국 주간거래(10:00~16:00)** 시세 조회도 가능합니다.

## 요청 (Request)

### Header

| Element | 한글명 | Type | Required | Length | Description |
|---------|--------|------|----------|--------|-------------|
| **approval_key** | 웹소켓 접속키 | String | Y | 286 | 실시간 (웹소켓) 접속키 발급 API(/oauth2/Approval)를 사용하여 발급받은 키 |
| **tr_type** | 등록/해제 | String | Y | 1 | 1: 등록, 2: 해제 |
| **custtype** | 고객 타입 | String | Y | 1 | B: 법인, P: 개인 |
| **content-type** | 컨텐츠타입 | String | Y | 20 | utf-8 |

### Body

| Element | 한글명 | Type | Required | Length | Description |
|---------|--------|------|----------|--------|-------------|
| **tr_id** | 거래ID | String | Y | 7 | `HDFSCNT0` |
| **tr_key** | D거래소명종목코드 | String | Y | 6 | 하단 규칙 참조 |

#### tr_key 입력 규칙

1. **미국 야간거래 / 아시아 주간거래 - 무료시세**
    - 형식: `D` + 시장구분(3자리) + 종목코드
    - 예시: `DNASAAPL` (D + NAS + AAPL)
    - 시장구분:
        - 미국: `NYS` (뉴욕), `NAS` (나스닥), `AMS` (아멕스)
        - 아시아: `TSE` (도쿄), `HKS` (홍콩), `SHS` (상해), `SZS` (심천), `HSX` (호치민), `HNX` (하노이)

2. **미국 야간거래 / 아시아 주간거래 - 유료시세**
    - 유료시세 신청 시에만 수신 가능
    - 형식: `R` + 시장구분(3자리) + 종목코드
    - 예시: `RNASAAPL` (R + NAS + AAPL)
    - 시장구분: 위와 동일

3. **미국 주간거래**
    - 형식: `R` + 시장구분(3자리) + 종목코드
    - 예시: `RBAQAAPL` (R + BAQ + AAPL)
    - 시장구분: `BAY` (뉴욕 주간), `BAQ` (나스닥 주간), `BAA` (아멕스 주간)

#### Request Data Class (Python)
```python
from dataclasses import dataclass

@dataclass
class RequestHeader:
    approval_key: str    #웹소켓 접속키
    tr_type: str         #등록/해제
    custtype: str        #고객 타입
    content_type: str    #컨텐츠타입

@dataclass
class RequestBody:
    tr_id: str           #거래ID
    tr_key: str          #D거래소명종목코드
```
