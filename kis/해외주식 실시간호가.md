# 해외주식 실시간호가 [실시간-021]

## API 정보

| 항목 | 내용 |
|------|------|
| **Method** | POST |
| **URL** | /tryitout/HDFSASP0 |
| **실전 Domain** | ws://ops.koreainvestment.com:21000 |
| **모의 Domain** | 모의투자 미지원 |
| **실전 TR ID** | `HDFSASP0` |
| **모의 TR ID** | 모의투자 미지원 |
| **Format** | JSON |
| **Content-Type** | utf-8 |

## 개요

해외주식 실시간호가 API를 이용하여 미국 실시간 10호가(매수/매도) 시세가 무료로 제공됩니다. (미국은 유료시세 제공 X)
아시아 국가의 경우, HTS(efriend Plus) [7781] 시세신청(실시간) 화면에서 유료 서비스 신청 시, "해외주식 실시간호가 HDFSASP0" 을 이용하여 아시아국가 유료시세(실시간호가)를 받아보실 수 있습니다.

- **미국**: 실시간 무료, 매수/매도 각 10호가 (0분지연, 나스닥 마켓센터에서 거래되는 호가 및 호가 잔량 정보)
- **아시아(홍콩, 베트남, 중국, 일본)**: 실시간 유료 (단, 중국은 HTS[7781]에서 실시간시세 무료로 신청 후 이용 가능)

해당 API로 미국주간거래(10:00~16:00) 시세 조회도 가능합니다.

### [미국주식시세 이용시 유의사항]
1. 무료 실시간 시세(나스닥 토탈뷰)를 별도 신청없이 제공하고 있으며, 유료 시세 서비스를 신청하시더라도 OpenAPI의 경우 무료 시세로만 제공하고 있습니다.
    - 무료(매수/매도 각 10호가) : 나스닥 마켓센터에서 거래되는 호가 및 호가 잔량 정보
    - 유료(매수/매도 각 1호가) : OpenAPI 서비스 미제공
2. 무료 실시간 시세 서비스는 유료 실시간 시세 서비스 대비 평균 50% 수준에 해당하는 정보이므로 정보 차이가 있을 수 있습니다.
3. 종목별 과거 데이터는 장 종료 후(오후 12시경) 유료 실시간 시세 서비스 데이터와 동일하게 업데이트됩니다.

## 요청 (Request)

### Header

| Element | 한글명 | Type | Required | Length | Description |
|---------|--------|------|----------|--------|-------------|
| **approval_key** | 웹소켓 접속키 | String | Y | 286 | 실시간 (웹소켓) 접속키 발급 API(/oauth2/Approval)를 사용하여 발급받은 키 |
| **custtype** | 고객 타입 | String | Y | 1 | B: 법인, P: 개인 |
| **tr_type** | 등록/해제 | String | Y | 1 | 1: 등록, 2: 해제 |
| **content-type** | 컨텐츠타입 | String | Y | 20 | utf-8 |

### Body

| Element | 한글명 | Type | Required | Length | Description |
|---------|--------|------|----------|--------|-------------|
| **tr_id** | 거래ID | String | Y | 7 | `HDFSASP0` |
| **tr_key** | R거래소명종목코드 | String | Y | 6 | 하단 규칙 참조 |

#### tr_key 입력 규칙

1. **미국 야간거래 - 무료시세**
    - 형식: `D` + 시장구분(3자리) + 종목코드
    - 예시: `DNASAAPL` (D + NAS + AAPL)
    - 시장구분: `NYS` (뉴욕), `NAS` (나스닥), `AMS` (아멕스)

2. **미국 주간거래**
    - 형식: `R` + 시장구분(3자리) + 종목코드
    - 예시: `RBAQAAPL` (R + BAQ + AAPL)
    - 시장구분: `BAY` (뉴욕 주간), `BAQ` (나스닥 주간), `BAA` (아멕스 주간)

3. **아시아국가 - 유료시세**
    - 형식: `R` + 시장구분(3자리) + 종목코드
    - 예시: `RHKS00003` (R + HKS + 00003)
    - 시장구분: `TSE` (도쿄), `HKS` (홍콩), `SHS` (상해), `SZS` (심천), `HSX` (호치민), `HNX` (하노이)

#### Request Data Class (Python)
```python
from dataclasses import dataclass

@dataclass
class RequestHeader:
    approval_key: str    #웹소켓 접속키
    custtype: str        #고객 타입
    tr_type: str         #등록/해제
    content_type: str    #컨텐츠타입

@dataclass
class RequestBody:
    tr_id: str           #거래ID
    tr_key: str          #R거래소명종목코드
```
